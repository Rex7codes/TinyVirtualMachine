TinyVM Instruction Set Architecture (ISA)

TinyVM is a stack-based virtual machine. Arithmetic and logical instructions pop operands from the top of the operand stack and push the computed result back.

OpcodeOperandDescription
PUSH_CONSTliteralPushes a numeric or string constant onto the operand stack.
LOAD_VARvar_namePushes the current value of var_name onto the stack.
STORE_VARvar_namePops top of stack and stores it in var_name.
ADD / SUB / MUL / DIV / MOD—Pops b, pops a, pushes a op b.
CMP_EQ / NEQ / LT / GT / LTE / GTE—Pops b, pops a, pushes boolean result.
JMPaddrUnconditional jump to bytecode instruction address.
JMP_IF_FALSEaddrPops top of stack; jumps to addr if falsy.
PRINT—Pops top of stack and writes it to standard output.
HALT—Terminates VM execution cleanly.
